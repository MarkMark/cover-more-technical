# AI Tooling

This project used AI assistance as part of the development workflow. AI output was treated as a proposal, not as automatically accepted code.

## AI Tools Used

- Codex
- Agents:
  - Codex main agent
  - Codex worker agents for parallel implementation and review
- Skills:
  - `brainstorming`
  - `building-components`
  - `dispatching-parallel-agents`
  - `executing-plans`
  - `finishing-a-development-branch`
  - `git-commit`
  - `karpathy-guidelines`
  - `shadcn`
  - `subagent-driven-development`
  - `tailwind-css-patterns`
  - `typescript-advanced-types`
  - `using-superpowers`
  - `vercel-react-best-practices`
  - `verification-before-completion`
  - `writing-plans`

## AI Was Used For

- Planning implementation tasks
- Discussing architecture and tradeoffs
- Generating implementation scaffolding
- Writing documentation and development logs
- Running focused implementation tasks in parallel
- Reviewing changes before commit
- Verification planning and command execution

## Review Standard

Every generated change was reviewed before commit.

No code was accepted without understanding what it did and why it was appropriate for this repository.
